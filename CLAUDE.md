# kucherbaev.com

Personal website of Pavel Kucherbaev. Static HTML/CSS, no build step.
`index.html` is the page, `css/style.css` is the stylesheet, `images/`
holds screenshots and logos.

## Writing style

All copy on this site (headings, body text, alt text, link labels) must
follow these rules:

- Never use em dashes (—). Use a period, comma, or colon instead.
- Never use words like "actually".
- Keep language short, clear, direct, and precise. Prefer short sentences
  over long ones. Cut filler words.

En dashes for number ranges (e.g. `2018–2019`) are fine — that's not an
em dash.
